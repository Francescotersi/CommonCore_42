---DEFINIZIONE DI DOCKER---
Docker è una piattaforma open source che permette agli sviluppatori di creare,
distribuire ed eseguire applicazioni all'interno di container.
In termini semplici, un container è un'unità standardizzata di software che
impacchetta il codice di un'applicazione e tutte le sue dipendenze 
(librerie, runtime, impostazioni e file di sistema necessari) in
modo che l'applicazione possa funzionare in modo rapido 
e affidabile su qualsiasi ambiente di calcolo, indipendentemente dal
sistema operativo host.
